Escritorio de prueba · GESTORA ERP v3.1

Aplicación de escritorio "legada" con datos ficticios, para medir al agente autónomo. Se opera solo por VNC.

  • /websockify: VNC por WebSocket (lo usa el agente).
  • POST /__reset y POST /__check: reinicio y evaluación (requieren token).
  • /health: estado de la pantalla, la aplicación y el VNC.
